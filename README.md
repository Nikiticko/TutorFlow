# TutorFlow — Telegram Mini App

Личный журнал преподавателя на Vue 3 + Vite. Приложение открывается внутри Telegram через кнопку приложения у бота. Подключён официальный Telegram Mini Apps SDK: `ready`, `expand`, тема клиента, штатная кнопка «Назад», безопасные отступы.

## Кнопка Open / «Открыть приложение» в Telegram

1. Соберите приложение: `npm ci`, затем `npm run build`.
2. Разместите содержимое `dist/` на статическом хостинге с публичным HTTPS-адресом. Серверная логика для этого прототипа не нужна.
3. В [@BotFather](https://t.me/BotFather) выберите бота `@Tutor_Flow_CRM_bot`. Откройте Bot Settings → Configure Mini App → Enable Mini App и задайте HTTPS-адрес приложения. Это настройка Main Mini App: в профиле появится кнопка запуска.
4. Чтобы добавить кнопку в чат с ботом, используйте `/setmenubutton`: выберите бота, укажите тот же HTTPS-адрес и текст «Открыть».
5. Откройте профиль бота либо ссылку `https://t.me/Tutor_Flow_CRM_bot?startapp` и нажмите кнопку приложения.

Токен бота во frontend не нужен. Локальный адрес `localhost` не является адресом опубликованного приложения. HTTPS-хостинг и настройка BotFather выполняются отдельно; репозиторий сам не создаёт кнопку в Telegram.

Документация: [Main Mini App](https://core.telegram.org/bots/webapps#launching-the-main-mini-app), [кнопка меню](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button).

## Локальная разработка

```sh
npm ci
npm run dev
```

Vite запускается на `http://localhost:5173`. В обычном браузере доступен предпросмотр тех же экранов с собственной кнопкой «Назад»; внутри Telegram используется кнопка клиента. Остановка: `Ctrl+C`.

```sh
npm test
npm run build
```

## Возможности и данные

Только три вкладки: ученики, проведённые уроки, статистика. Настройки открываются шестерёнкой. Оплата увеличивает баланс; сохранение нового урока списывает одно занятие. Отрицательный баланс разрешён. Редактирование урока не списывает занятие повторно, историческая стоимость сохраняется.

Mock-данные и localStorage (`tutorflow-v1`). Существующие записи сохраняются при обновлении этой версии. Данные остаются в конкретном браузере/WebView и не синхронизируются между устройствами. Смена валюты меняет обозначение без пересчёта сумм. Приложение не использует Telegram-данные как авторизацию.

Backend, база данных, обработчик сообщений бота, роли, расписание и онлайн-платежи отсутствуют.

## Проверка в Telegram после размещения

- Кнопка приложения открывает список учеников внутри клиента.
- Светлая/тёмная тема и её смена применяются без перезагрузки.
- Кнопка Telegram «Назад» возвращает на предыдущий экран, на корневых вкладках скрыта.
- Сценарий: Давид (3) → урок (2) → оплата 8 занятий (10) → история → статистика.
- Повторное открытие сохраняет изменения в том же WebView.
